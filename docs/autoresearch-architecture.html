BG BashGym AutoResearch

Interactive architecture

Autonomous model experimentation, from baseline to the next iteration.

An agent inspects results and chooses what to change. BashGym runs the training and evaluation work, preserves the experiment record, and returns a comparison the agent can act on.

The agent directs the research Forms hypotheses, changes data or training, interprets failures, and selects the next experiment.
BashGym executes the experiment Runs stages, tracks lineage, evaluates against fixed tasks, compares outcomes, and produces the report.

What an iteration may change

Each candidate should have a specific reason to exist.

  • Training examples, filtering, or data mixture
  • SFT, preference optimization, or verifier-based RL
  • Learning rate, schedule, sampling, or batch settings
  • Reward, verifier, environment, or training code

What remains comparable

The experiment contract prevents the target from moving between runs.

  • Held-out task set and contamination boundary
  • Primary metric definitions and regression checks
  • Reference baseline and keep/discard rule
  • Recorded lineage for data, recipe, model, and evaluator

Training and evaluation

Choose the method that matches the available signal.

BashGym does not assume one training strategy. The intervention depends on the data and the feedback available for the experiment.

Training side

Construct the intervention

Bring a dataset or derive one from verified traces, synthetic examples, preferences, or environment rollouts. Curate, validate, and decontaminate it before training.

→

Evaluation side

Measure without leakage

Keep held-out tasks outside training. Run the base model and every candidate through the same evaluator, then inspect both the primary metric and protected regressions.

Data preparation checklist
SchemaEvery row satisfies the selected trainer’s input contract.
VerificationDemonstrations and rewards are checked before they become training signal.
DecontaminationTraining rows are compared against held-out tasks and known evaluation material.
VersioningThe exact data revision and transformation recipe are recorded for each run.
CoverageFailure categories are represented intentionally instead of by raw volume alone.
AblationsChange one defensible intervention at a time when attributing an effect matters.

Agent workflow

Use the agent environment you already work in.

BashGym adds experiment tools and shared state. The host agent keeps its own goals, plans, conversation context, tools, and subagents; there is no second planning system to manage.
